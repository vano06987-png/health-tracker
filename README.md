# Трекер Здоровья (Health & Wellness Tracker)

Веб-приложение для ведения здорового образа жизни, созданное в рамках учебного проекта. 

## 📌 О проекте
Приложение помогает пользователю отслеживать три ключевых аспекта здоровья:
- **Дневник питания** (учет калорий).
- **Трекер воды** (учет водного баланса).
- **Трекер активности** (учет выполненных упражнений).

*Проект разработан с учетом потребностей людей старшего возраста (крупный шрифт, контрастный интерфейс), но подходит для универсального использования.*

## 🚀 Функционал (MVP)
- Добавление записей о еде, воде и физической активности.
- Настройка индивидуальных дневных целей (норма воды и калорий).
- Сохранение данных в браузере пользователя (`localStorage`), благодаря чему данные не пропадают при перезагрузке страницы.
- Визуализация прогресса (прогресс-бары).

## 🛠️ Технологии
- HTML5
- CSS3 (адаптивная верстка)
- JavaScript (Vanilla JS)
- `localStorage` (для хранения данных на стороне клиента)

## ⚠️ Медицинский дисклеймер
**Важно!** Данное приложение создано исключительно в ознакомительных и оздоровительных целях. Оно помогает вести здоровый образ жизни, но **не является медицинским изделием**. Информация, предоставляемая приложением, не может служить заменой профессиональной медицинской консультации, диагностики или лечения. Перед началом любых упражнений или изменением рациона питания обязательно проконсультируйтесь с вашим лечащим врачом.

## 📂 Как запустить
Проект представляет собой один файл `index.html`. Чтобы запустить его, достаточно скачать файл из репозитория и открыть двойным кликом в любом браузере.
